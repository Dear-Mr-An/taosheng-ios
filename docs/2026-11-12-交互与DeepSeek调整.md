# 交互与 DeepSeek 调整

范围：只修改 iOS 工程，Android 作为参照。不提交、不推送、不发布，不删除历史录音或口播卡。

源码交付

- 四种收音模式依次为日常、会议、培训、通话，移除口播稿入口和新卡生成。
- 右下角同一个 + 轻点打字、长按说话；松手停止采集，最多等待 1.5 秒识别尾字后填草稿。旁边提示文字不处理手势。
- 整理模型改为两张卡：DeepSeek 配置与余额、整理时间与选项。无其他服务商入口或备用切换。
- 官方余额接口显示实际余额、赠送额度、更新时间和错误，优先 CNY，成功缓存一小时，支持手动刷新；低额提示仅在页面展示。
- 短语音权限等待与回调绑定会话；取消不再异步启动，短语音暂停全天采集，结束按原开关恢复。
- 停录排空写入队列，拒绝迟到音频；跨队列复制系统 buffer，文件名改 UUID；录音保存模式，后续转写与整理使用历史模式。
- 自动整理遵守开关、间隔与整点，包含历史积压，按连续模式和每批至多 200 段处理。失败显示错误，空结果不标已整理。
- 待办拆卡失败保留草稿，取消请求不继续落卡；一小时后提醒直接由单次菜单操作添加。

独立审查后的修正

1. 超过 200 段的积压不再因当日成功记录而永久跳过；旧日期也进入自动整理范围。
2. 自动成功记录独立保存，白天手动整理不取消晚上的定时任务；调整到更晚时间仍可触发。
3. 保存 DeepSeek 不清空旧服务商列表，另存显式保存标记，清空密钥后不会从旧列表复活。
4. 完成提示落库时用条件 UPDATE 再核对当前状态，不覆盖请求等待期间用户设置的「不用记」。
5. 部分批次失败只刷新已保存内容，不触发整轮「整理完成」推送；成功批次保留，失败批次可重试。

约束和取舍

- iOS 16+、SwiftUI、系统框架，无新增第三方运行依赖。
- DeepSeek 固定官方 HTTPS，只迁移官方地址对应密钥，其他服务商密钥不得发送给 DeepSeek。
- 旧录音没有模式时按日常兼容，不猜历史模式。
- 检测只验证连接及 JSON，不包含 Android 原版工具调用和流式检测。
- 地点与环境音仅在「整理时参考地点和环境音」开启时附加发送；相关采集需另开。
- 密钥仍沿用 UserDefaults，未实现 Keychain；不能声称加密安全区。
- 当天定时任务成功后新增或稍后才转写的内容会留待下一次自动任务，App 挂起时不保证准点执行。
